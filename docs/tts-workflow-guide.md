# WT 语音包制作 · 作业流程指南

> 面向使用者的操作手册：从原始素材到可安装的语音包，全流程在应用内完成，
> **无需手动编辑任何中间文件**。界面入口：主页 → 「TTS生成」→ 选择模型 → 语音批量生成工作台。

---

## 0 · 流程全景

```
原始音频素材
   │
   ├─ [数据集工具 · 语音切分(0b)]   长音频 → 语句片段
   ├─ [数据集工具 · 语音识别(0c)]   片段 → .list 清单（文本标注，可人工校对）
   │
   ├─ [微调训练 · 一键三连(1ABC)]   .list → 训练格式化产物（文本/BERT/HuBERT/语义）
   ├─ [微调训练 · SoVITS(s2)]       音色模型
   ├─ [微调训练 · GPT(s1)]          韵律模型
   │        └─ 训练完成 → 权重路径自动回填到右侧「推理」
   │
   ├─ [语音批量生成]                台词表 → 逐条合成 → 试听/重新生成
   │
   └─ [更多 → 打开/导出]             .vt 工程（未签名可编辑 / 签名后只读）+ 整包清单(.vtmanifest) → 安装进游戏
```

两个模型的分工：

| | GPT-SoVITS | CosyVoice 3 GGUF |
|---|---|---|
| 定位 | 可微调，效果上限更高 | 推理专用，低配（纯 CPU）可用 |
| 微调 | 支持（左侧「微调训练」子页） | 不支持（显示模型信息面板） |
| 显卡 | 建议独显 | 无硬性要求 |

## 1 · 准备素材

- 原始音频：一段较长的干净语音（游戏配音、朗读均可），WAV 或常见音频格式。
- 安静环境录制效果最好；有明显背景音乐请先用去歌声/分离工具处理（UVR5 类工具，
  官方 webui 的「0a 人声伴奏分离」即此用途；本工具暂未内置，可离线处理后再导入）。

## 2 · 数据集工具（左侧「数据集工具」子页）

### 2.1 语音切分（0b）

把长音频按静音自动切成语句片段：

1. 「音频输入路径」：填原始长音频（文件或文件夹）。
2. 「切分输出目录」：保持默认即可（在上游 GPT-SoVITS 的 output 下）。
3. 其余参数用默认值即可满足大多数情况；素材语速快/句间停顿短时，
   可适当调大「最短段长 min_length」。
4. 点「开始切片」。切片在**上游 torch 环境**执行，日志在下方日志区。

### 2.2 语音识别（0c，生成 .list）

对切好的片段做语音识别，生成训练所需的 `.list` 清单：

1. 「识别输入目录」：**切片完成后自动回填**（也可手动改）。
2. 「识别方式」：`faster-whisper`（本地，推荐）或 `funasr`（达摩院在线，需自备 API Key）。
3. 「模型规模」默认 `large-v3`；「识别语言」按素材语言选择（zh/ja/en/ko/yue）。
4. 点「开始识别」。完成后 `.list` 路径**自动回填**到「微调训练」子页的「数据集清单」。

> 建议打开 `.list` 人工校对一遍：识别错了文字，训出来的模型也会"念错"。
> `.list` 行格式：`wav路径|说话人|语言|文本`，语言只认 zh/ja/en/ko/yue（不要写 AUTO）。

## 3 · 微调训练（「微调训练」子页）

1. 「数据集清单」「音频目录」已由上一步自动回填；「实验名」自定义（字母/数字）。
2. 「前置体检」按钮：一键检查格式化产物（文本/BERT/HuBERT/32k 音频/语义）是否就绪。
3. 「一键三连」：执行数据集格式化（文本分词 + BERT + HuBERT + 语义标注）。
   首次运行会下载/加载预训练模型，耐心等待；日志区实时输出。
4. 「s2 训练」：训练音色模型（SoVITS）。默认轮数够用；过拟合时减轮数。
5. 「s1 训练」：训练韵律模型（GPT）。
6. 训练完成（日志出现"全部阶段完成"）后，应用会**自动发现新权重**并回填到
   右侧「推理」的权重输入框——点「应用权重」即可让批量生成使用微调后的音色。

> 训练在**上游 torch 环境**执行（「Python 解释器」字段指定该环境解释器），
> 本应用自带的 venv 不含 torch。

## 4 · 批量生成（右侧「语音生成列表」）

1. 「添加行」逐条添加台词；「名称」即输出文件名（须符合 WT_DEFAULT 规则：ASCII + .wav）。
2. 「音色」列：填参考音频路径（GPT-SoVITS 零样本克隆按行指定参考音频）。
3. 「▸ 推理参数」展开：语速 / top_k / top_p / temperature / 文本切分 / 固定随机种子。
   - 固定随机种子（非 0）= 同文本同参数产出**完全相同**的音频，便于对比调参。
4. 勾选要生成的行（或「生成未完成项」只补缺），点「生成选中行」。
   生成在后台串行执行；可随时「停止」，已完成的行不受影响。
5. 每行「试听」即时检查；不满意的行单独「重新生成」。

## 5 · 导出与安装

- **工程文件就是 `.vt`**：「更多 → 打开工程…」打开后即可编辑，改动会自动保存写回该文件
  （默认工作文件在项目内 `temp/voice-output/voice_project.vt`）。
- 「更多 → 导出 .vt…」：把当前表**另存为**一个新的 `.vt`（未签名，可继续编辑）。
- 「更多 → 签名并导出 .vt」：产出**已签名并自动上锁**的只读工程（签名 = 防篡改标识，
  接收方打开时显示锁状态与签名者指纹）。要修改已签名的工程，用「更多 → 解锁以编辑」
  去掉只读锁（保存后该文件变为未签名），或直接另存为新文件。
- 「更多 → 导出整包清单…」：对"音频产物 + .vt"的整包生成清单签名，接收方可
  逐文件校验完整性。
- 安装：按 War Thunder 语音包惯例放置 bank/相关文件（此步骤沿用既有安装流程）。

## 6 · 常见问题

| 现象 | 原因与处理 |
|---|---|
| 生成按钮灰 + "正在连接推理服务…" | 后端探活/拉起中（CosyVoice 3 首次拉起最长约 3 分钟），稍候 |
| "未检测到推理服务，当前为演示模式" | 未安装对应模型或服务未启动；生成的是占位音频，仅供流程联调 |
| 切分后识别输出为空 | 素材信噪比低或语言选错；先试 faster-whisper + large-v3 |
| 台词被截断/语速异常（CosyVoice 3） | 参考音频与转写文本不匹配（CrispASR #334）；让工具自动转写，勿手填不确定的文本 |
| 训练产物没被发现 | 「实验名」与训练时不一致；权重目录按实验名命名，改名后重新训练即可 |
